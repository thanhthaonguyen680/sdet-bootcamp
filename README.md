# Lộ trình tự học SDET cho team QC/QA: JavaScript, Playwright và CI/CD

Mình xây dựng lộ trình này dành cho các thành viên trong team QC/QA có nhu cầu học và từng bước thực hành theo hướng SDET. Nội dung được chia thành 5 tuần, từ JavaScript nền tảng đến Playwright và CI/CD. Bạn có thể học và làm bài trực tiếp trên trình duyệt, không cần cài đặt gì.

**Dùng thử:** https://TEN-CUA-BAN.github.io/sdet-bootcamp/

## Nội dung

| Tuần | Chủ đề |
|------|--------|
| 1 | JavaScript nền tảng (25 bài) |
| 2 | Ôn tập qua 18 bài thuật toán kinh điển |
| 3 | JavaScript hiện đại: ES6+, Promise, async/await |
| 4 | Playwright + TypeScript: locator, assertion, Page Object Model, fixture, dự án POM hoàn chỉnh |
| 5 | CI/CD với GitHub Actions: secrets, artifact, matrix, sharding, lịch chạy |

## Tính năng

- Editor có tô màu cú pháp, chấm bài tự động, bài giảng, gợi ý và lời giải cho từng bài
- Trang web mẫu (sàn giao dịch giả lập) để luyện locator và viết test Playwright
- Bộ chấm "cài bug" vào trang để kiểm tra test có thực sự bắt được lỗi không
- Mô phỏng GitHub Actions: chạy workflow YAML, xem từng job, từng bước và log
- Tiến độ lưu tự động trong trình duyệt

## Về dự án

Mục tiêu của dự án là giúp các thành viên QC/QA trong team có một lộ trình rõ ràng để tự học, thực hành và follow từng tuần. Nội dung và công cụ do mình thiết kế với sự hỗ trợ của AI (Claude).
